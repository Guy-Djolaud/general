# Guy-Arnold Djolaud – Labour and Macroeconomics

Source of <https://guy-djolaud.github.io/general/>: a single static page (`index.html`, no build step).

Positioning: applied macroeconomics for a policy research audience — inflation and economic slack,
monetary policy and household balance sheets, labour market power. Canadian data throughout.

- Edit papers, methods and experience directly in `index.html` (sections `#research`, `#methods`, `#experience`).
- Each paper has an anchor (`#nairu`, `#tariffs-oil`, `#labour-market-power`, `#monetary-union`) so a single
  paper can be linked directly in an email.
- PDFs live in `files/`.
- Other sites: academic <https://guy-djolaud.github.io/> · macro <https://guy-djolaud.github.io/macro/>
